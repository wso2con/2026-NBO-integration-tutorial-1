# 2026-NBO-integration-tutorial-1

A hands-on tutorial series demonstrating integration capabilities using [WSO2 Integration Platform](https://wso2.com/integration-platform/). The tutorial is organized into three parts, each focusing on a different integration pattern.

## Prerequisites

- [WSO2 Integrator - V 5.1.0](https://github.com/wso2/product-integrator/releases/tag/v5.1.0-alpha5)
- [WSO2 Integration Platform Cloud](https://wso2.com/integration-platform/docs/get-started/setup/cloud-setup) — launch WSO2 Integrator in a browser-based cloud editor.

## Tutorial Structure

This tutorial has three parts:

- **Part 1 - Workflow Capabilities**: Focuses on building workflow-driven integrations, using an expense approval workflow as the example. See [part-1-expense-approval-workflow](./part-1-expense-approval-workflow) and refer [Workflow Docs](https://integration-doc.ne.choreoapps.dev/workflows/overview)
- **Part 2 - Exposing a REST API as an MCP Service**: Focuses on exposing an existing REST API as a Model Context Protocol (MCP) service.
- **Part 3 - RAG Pipeline**: Focuses on building a Retrieval-Augmented Generation (RAG) pipeline to expose enterprise data to agentic applications.
